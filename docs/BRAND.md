# FRAMEZERO LAB visual identity

## Brand idea

FRAMEZERO LAB is an independent engineering workbench. Its identity is precise, restrained, high-contrast, and readable. The original geometric mark combines a framed core with offset signal planes to suggest runtime layers and graphics translation. It does not reuse game, publisher, console, or upstream project logos.

## Primary palette

| Token | Hex | Use |
|---|---|---|
| Deep Space | #080E1C | Main background |
| Carbon | #101D31 | Panels and surfaces |
| Ion Cyan | #57D9F5 | Primary accent and active states |
| Signal Blue | #4A8DFF | Secondary technical highlight |
| Plasma Violet | #9D8BFF | Secondary accent |
| Ice White | #F2F6FF | Main text |
| Slate | #9AA8BE | Supporting text |

Use cyan sparingly for active controls and key status. Do not use accent colors for long paragraphs. Warnings must remain distinguishable from ordinary decoration.

## Typography

Use system fonts without bundling font files:

- Windows: Segoe UI
- macOS: system sans-serif
- Linux: system sans-serif / Inter when installed
- Android: Roboto

Use tabular numerals for versions, measurements, and diagnostic output.

## Logo use

- Use **assets/framezero-mark.svg** on dark or transparent backgrounds.
- Preserve aspect ratio and clear space.
- Do not imitate Rockstar, GTA, Xbox, Leonida, or upstream project marks.
- The mark identifies the FRAMEZERO workbench; it does not imply a finished game, official status, or ownership of upstream code.

## Interface principles

1. Evidence before claims.
2. Diagnostics must explain the detected condition and next action.
3. Distinguish missing, warning, optional, upstream-reported, and tested states.
4. Keep common setup tasks visible; keep advanced details accessible.
5. Keep all package paths and generated content local.
6. Keep the desktop console responsive while child processes run.

## Project language

Use "runtime research", "graphics compatibility", "local diagnostics", and "reproducible experiments". Do not describe FRAMEZERO as the developer of the upstream engine or as a finished GTA VI PC port.
