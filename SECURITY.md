# Security policy

## Scope

Security reports are welcome for FRAMEZERO-owned code, including the command-line interface, desktop console, diagnostics, tests, and repository automation.

The upstream engine is maintained in a separate Git submodule. Report upstream vulnerabilities to its maintainers using the security process published by that repository.

## Reporting

Do not publish credentials, private package contents, game files, keys, extracted assets, or exploit details in a public issue. Use GitHub's private vulnerability reporting feature when it is enabled for this repository. Otherwise, contact the repository owner through a private GitHub channel.

## Supported versions

Only the latest commit on the default branch is actively maintained while the project is in pre-release development.

## Data boundary

Do not attach proprietary game packages, binaries, keys, saves, or extracted content to a security report. A minimal reproduction using synthetic data is preferred.
